## Correcciones para Windows
- **Herramientas necesarias** ya no abre una ventana de consola que aparecía y se cerraba en bucle.
- Detecta si a Visual Studio le falta el enlazador de C++ (`link.exe`) o el SDK de Windows, y ofrece **Reparar** la instalación.
- Si la compilación falla porque no se encuentra el enlazador, Raxorin Studio lo explica y te lleva al asistente.

## Instalar
- macOS: `.dmg` (Apple Silicon o Intel)
- Windows: `-setup.exe` o `.msi`
- Linux: `.AppImage` (se actualiza sola), `.deb` o `.rpm`
