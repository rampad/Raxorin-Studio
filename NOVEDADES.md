## Conectar con IA (MCP)
- **Raxorin Studio es un servidor MCP.** Claude Code, Claude Desktop y otras IA pueden compilar tus proyectos y recibir los errores con su archivo y línea, revisar con Clippy, ejecutar las pruebas y el programa, explicar errores, agregar paquetes, crear proyectos y escribir ventanas de Slint que el diseñador entiende.
- **Ayuda → Conectar con IA (MCP)…** trae el comando para Claude Code y un botón para agregarlo a Claude Desktop.
- La IA solo usa las carpetas que autorices; puedes limitarla a la del proyecto abierto.
- Guía: [raxorin.dev/guias/mcp](https://raxorin.dev/guias/mcp/).
- La documentación (F1) se abre en el idioma de la app.

## Connect to AI (MCP)
- **Raxorin Studio is an MCP server.** Claude Code, Claude Desktop and other AIs can build your projects and get errors with their file and line, check with Clippy, run the tests and the program, explain errors, add packages, create projects and write Slint windows the designer understands.
- **Help → Connect to AI (MCP)…** has the command for Claude Code and a button to add it to Claude Desktop.
- The AI only uses the folders you allow; you can limit it to the open project's folder.
- Guide: [raxorin.dev/en/guias/mcp](https://raxorin.dev/en/guias/mcp/).
- The documentation (F1) opens in the app's language.
